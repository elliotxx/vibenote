# Markdown Block Conventions

## 原则

- Markdown block 是纯文本记录单元。
- 视觉增强不能改变复制结果和保存格式。
- 输入辅助应减少打断，不增加新面板或复杂模式。
- AI 能力默认限制在当前 block 或选区。

## 支持能力

- 语法高亮：标题、列表、任务列表、引用、链接、图片语法、分割线、代码块、行内代码、加粗。
- 快捷输入：加粗、斜体、链接、有序列表、无序列表。
- 列表续行：Enter 自动续写，空列表项退出。
- 任务列表：点击 checkbox 切换 Markdown 标记。
- 流程图：普通行或连续列表项中使用 ` -> ` 表达方向，阅读状态将整组内容显示为流程图，缩进列表项显示为分支。

## 存储约定

任务列表以 Markdown 原文保存：

```md
- [ ] task
- [x] done
```

图片继续以 Markdown 图片语法保存：

```md
![image](</absolute/path/to/image.png>)
```

流程图继续以原始 Markdown 文本保存，顶层流程可以带或不带列表标记，箭头两侧保留空格：

```md
变更感知 -> 搜得到 -> 搜得准
    -> 从 1 到 N -> 数据质量优化
  - 0 -> 1：接入
```

不带列表标记的顶格箭头链会成为顶层流程；带列表标记的写法继续兼容。直接以 `->` 开头的下一行会成为同一顶层逻辑下的分支路径。续行箭头的显示列决定它连接到父路径的哪个阶段（制表符和中日韩宽字符按屏幕宽度计算）；同一阶段的节点跨路径对齐。每个顶层 section 独立排布，节点最长约 22 个字符后换行；窄窗会改为纵向阅读，始终完整显示文本而不产生横向滚动。点击流程图会切回原始 Markdown，光标移出流程文本后恢复流程阅读视图。
