# Markdown Block Session Preview

## Goal

Let a writer explicitly switch one Markdown block from source text to a read-only rendered view, then return safely to the original source. The mode belongs to the current editor session only: it never changes the note format or writes a preview field into a block delimiter.

This is not a default preview, document-wide preview, or WYSIWYG editor. Raw HTML, Mermaid, formulas, keyboard shortcuts, persistent mode state, block IDs, and delimiter changes remain out of scope.

## Interaction

- A Markdown block toolbar places an Eye/EyeOff action between Format and Delete.
- The action is labelled `渲染此块` in source mode and `回到源码` in preview mode.
- Multiple Markdown blocks can be rendered independently, including blocks whose historical `created` values are identical.
- Double-clicking a rendered block returns to source and places the cursor at the start of that block's content.
- Reloading the editor clears all rendered-block state.

## Editor model

The editor keeps one CodeMirror document stream. A `StateField` stores the `content.from` anchors of rendered blocks. Anchors are mapped through document changes and resolved again against parsed Markdown blocks; `created` and optional `id` fields are not identities.

A block replacement widget presents the rendered HTML without changing the document string. Empty blocks use a block widget at `content.from` because a zero-length replacement is invalid. Language changes and deletions remove anchors that no longer resolve to a Markdown block.

Ordinary user transactions that begin in, or intersect, a rendered block are rejected as a whole by a `changeFilter`. Existing annotated internal block edits remain allowed, including task changes, formatting, AI actions, language changes, and deletion. Source decorations, strong-emphasis preview, and automatic language detection skip rendered blocks.

## Rendering and safety

Rendering uses `markdown-it` with raw HTML and linkification disabled, plus `markdown-it-multimd-table`. User HTML is escaped by the renderer; no executable HTML is inserted. Images use the same URL normalization helper as the inline image widget. Preview links open on a single click only when their URL uses HTTP or HTTPS, through the existing external-shell bridge.

Task inputs are generated by a custom renderer. Their `data-task-index` follows the same source-order expression used for edits, so a click updates exactly the corresponding `[ ]` or `[x]` marker through an internal transaction.

If rendering throws, the widget shows an English error message and the source-mode action remains available.

## Clipboard behavior

Editor copy and cut continue to expose Markdown source without block delimiters. The only new exception is a browser selection wholly inside one `.markdown-preview`: copying that selection returns its visible text. Cutting a preview selection copies visible text but does not mutate the read-only block.

## Verification

Playwright coverage proves toolbar scope, source preservation, reload reset, whole-transaction protection, empty blocks, duplicate historical timestamps, language/delete cleanup, source and visible-text clipboard behavior, tasks, external links, tables, images, and double-click exit. Fixtures are synthetic.
