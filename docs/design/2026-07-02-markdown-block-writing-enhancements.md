# Markdown Block Writing Enhancements

## 背景

Vibenote 的 Markdown block 需要保持纯文本、低干扰、可复制的写作体验。第一优先级增强聚焦“顺手写下去”，不引入重型预览模式、目录树或破坏性自动整理。

## 范围

本次实现覆盖四类第一优先级能力：

- 轻量 Markdown 语法高亮：标题、列表、任务列表、引用、链接、图片语法、分割线、代码块、行内代码、加粗。
- 常用快捷输入：加粗、斜体、链接、有序列表、无序列表。
- 列表续行：无序列表、有序列表、空列表项退出。
- 任务列表：点击 checkbox 在 `- [ ]` 与 `- [x]` 之间切换。

## 非目标

- 不做完整 Markdown 预览模式。
- 不做多文档知识库能力。
- 不做全局 AI 自动整理。
- 不自动删除用户粘贴图片对应的本地文件。

## 交互约定

- 所有内容仍保存为 Markdown 纯文本。
- 视觉增强通过 CodeMirror decoration 完成，不改变底层文本结构。
- 快捷键只在当前 Markdown block 内生效。
- 任务 checkbox 点击只改写当前任务标记，不创建外部任务系统。

## 快捷键

| 快捷键 | 行为 |
| --- | --- |
| `Cmd/Ctrl+B` | 将选区包裹为 `**text**` |
| `Cmd/Ctrl+I` | 将选区包裹为 `*text*` |
| `Cmd/Ctrl+K` | 将选区转换为 `[text](url)` |
| `Cmd/Ctrl+Shift+8` | 当前行切换无序列表 |
| `Cmd/Ctrl+Shift+7` | 当前行切换有序列表 |
| `Enter` | 在列表项中续行；空列表项退出列表 |

## 验收标准

- Markdown 常见语法有可见高亮，但复制和保存仍是原始纯文本。
- 快捷键修改当前 Markdown block，不暴露或破坏隐藏 block delimiter。
- 列表续行符合常见纯文本编辑器行为。
- 任务 checkbox 点击后底层文本在 `- [ ]` 和 `- [x]` 之间切换。
- 全量 e2e 与生产构建通过。
