Vibenote

沉浸式、顺手、AI Native 的纯文本笔记。

一条 note stream，打开就能写。不先想目录、文件或格式——block 只是节奏，不是整理工作。

仅限 macOS Apple Silicon（arm64）

功能

少一点界面，多一点书写。

设计目标是安静、精确、就绪——足够用心，但不会打断记录。

  • 沉浸式记录

    没有侧边栏目录树、没有 tab、没有多 buffer 切换。打开就是唯一的 note stream。

  • Block 是节奏

    用边界分隔想法与片段，而不是把内容塞进文件夹。跳转、拆分、删除都围绕书写节奏。

  • 纯文本优先

    内容保存在本地 stream.txt：可读、可移植、容易备份，长期仍然是你的文字。

  • 快捷键不抢戏

    新增、拆分、选择、跳转——快捷键服务于输入，而不是把应用变成第二套 IDE。

  • AI 辅助，不改写原文

    围绕 block 边界提供非破坏性协助。AI 是旁观者，不是接管整理的编辑器。

  • 本地，可选 Git 备份

    数据留在本机。需要时开启单向 Git 快照，备份内部笔记与引用图片。

手感

打开 → 书写 → 自动保存

成功的标准很简单：进入写作台面，可靠地保存，block 边界刚好够导航。

  1. 01

    打开

    没有欢迎向导，没有先建文件夹。窗口就绪，光标已在书写位置。

  2. 02

    书写

    想法、日志、代码片段直接落入同一条流。需要时再按 block 切开。

  3. 03

    自动保存

    边写边存；退出前同步落盘。系统状态可见，但不会抢走注意力。
